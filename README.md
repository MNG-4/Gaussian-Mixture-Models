# Gaussian Mixture Models

## What is a Gaussian Mixture Model?

A **Gaussian Mixture Model (GMM)** is a probabilistic model that represents data as a weighted combination of several Gaussian (normal) distributions. Each Gaussian component can describe a group or pattern in the data, with its own mean and covariance. Together, the components can model complex distributions that a single Gaussian cannot capture.

For a data point **x**, a GMM defines the probability density

\[
p(\mathbf{x}) = \sum_{k=1}^{K} \pi_k\,\mathcal{N}(\mathbf{x}\mid\boldsymbol{\mu}_k,\boldsymbol{\Sigma}_k),
\]

where:

- \(K\) is the number of Gaussian components.
- \(\pi_k\) is the weight of component \(k\), with \(\pi_k \geq 0\) and \(\sum_{k=1}^{K}\pi_k=1\).
- \(\boldsymbol{\mu}_k\) is the component's mean.
- \(\boldsymbol{\Sigma}_k\) is its covariance matrix, describing the component's spread and shape.
- \(\mathcal{N}\) denotes the Gaussian probability density.

A useful way to think about a GMM is that each observation is generated by first selecting a component according to its weight, then sampling from that component's Gaussian distribution. The component identity is hidden, or **latent**, so the model estimates both the component parameters and the likely assignments of data points.

## How are GMMs fitted?

A common fitting method is **Expectation-Maximization (EM)**:

1. **Expectation step (E-step):** Estimate the probability, or responsibility, that each component generated each data point.
2. **Maximization step (M-step):** Update the component weights, means, and covariances using those probabilities.

The steps repeat until the parameters converge or a stopping condition is reached. Unlike hard clustering methods, GMMs provide **soft assignments**: a point can belong to multiple components with different probabilities.

## Applications

GMMs are used in many areas, including:

- **Clustering and segmentation:** Discovering groups in customer data, image pixels, or other measurements when cluster shapes may overlap.
- **Anomaly detection:** Flagging observations that have low probability under a model of typical data.
- **Density estimation:** Approximating a complex probability distribution for statistical analysis or simulation.
- **Computer vision:** Modeling color distributions, segmenting images, and representing visual features.
- **Speech and audio processing:** Modeling acoustic features and identifying patterns in speech or sound.
- **Finance and risk analysis:** Representing returns with multiple market regimes or modeling distributions with more than one peak.
- **Bioinformatics and scientific research:** Identifying subpopulations or recurring patterns in measurements.

## GMMs compared with k-means

Both GMMs and k-means can be used for clustering, but they make different assumptions. K-means assigns each point to exactly one cluster and groups points around cluster centers. A GMM models each cluster with a probability distribution and returns membership probabilities. This makes GMMs useful when clusters overlap or have different sizes and elliptical shapes. GMMs are more flexible, but they require selecting the number of components and can be more computationally demanding.

## Considerations

- The number of components \(K\) is typically chosen in advance, or selected using criteria such as AIC or BIC.
- Results can depend on initialization; multiple starts can help find a better fit.
- A GMM assumes the data can be reasonably approximated by a mixture of Gaussian components. It may not fit distributions with strongly non-Gaussian component shapes.
- Covariance choices affect model flexibility and the amount of data needed to estimate the model reliably.
